# JBroEngine 문서 뷰어

**굵은 글자**, *기울임*, ~~취소선~~과 `인라인 코드`를 표시합니다.
이 본문은 문단·표·코드를 가로질러 선택하고 복사할 수 있습니다. 한글과 이모지 😀도 같은 텍스트 위치를 사용합니다.

## 코드 예제

```jscript
script PatrolProbe
{
    [prop, range(0.0, 10.0)]
    Float speed = 3.0

    fn OnUpdate() override
    {
        Float step = speed * 0.016
    }
}
```

```cpp
// 기존 코드 편집기의 C++ 어휘 강조
```
