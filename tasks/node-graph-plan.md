## 2. 설계

### 2.1 층

| 층 | 자리 | 하는 일 |
|---|---|---|
| 그래프 모델 | 새 Tier E 모듈 `Modules/JBroNodeGraph`(JBroCore 만 본다) | 노드·핀·링크, 핀 타입 검사, 순환 검사, 위상 순서, YAML |
| 도메인 | 같은 모듈의 `Domain` | 핀 타입 표·노드 종류 표·변환 규칙. 도메인마다 하나 |
| 화면 모델 | `JBroEditor` 의 `NodeGraph/` | 노드·핀의 화면 자리, 판정, 마우스 손짓을 사건으로 바꾸기. ImGui 를 모른다 |
| 위젯 | `Widget::NodeGraphCanvas` | 그리기 목록으로 격자·링크·노드·핀을 그리고 입력을 화면 모델에 넘긴다 |
| 패널 | `NodeGraphPanel`(비고유, `.jgraph` 마다 하나) | 사건을 커맨드로 바꾸고, 고른 노드의 입력 기본값을 옆에서 고친다 |

### 2.2 모델

- 노드는 `NodeId`(그래프 안에서 늘 커지는 번호)·종류 이름·자리·입력마다 기본값이다. 핀은 종류의 입력·출력 차례 번호로 가리킨다.
- 링크는 출력 핀 → 입력 핀이다. 입력 하나에 링크는 하나이고, 새로 이으면 옛 링크를 갈아 치운다. 출력은 여럿에 나간다.
- 잇기는 같은 노드 금지·핀 타입 변환 가능·순환 없음을 본다. 그래프는 늘 DAG 다.
- 값은 `PinValue`(`Float` 넷)다. 핀 타입이 몇 칸을 쓰는지 안다.
- 파일에는 핀을 이름으로 적는다 - 도메인에서 핀 차례가 바뀌어도 잇기가 남는다. 모르는 노드 종류·모르는 핀은 읽을 때 문제로 알린다.

### 2.3 편집

- 노드 더하기·지우기·옮기기·잇기·끊기·기본값 바꾸기·붙여넣기는 모두 커맨드다. 커맨드는 바꾸기 전후의 그래프 글자를 떠 둔다(되살릴 값을 먼저 뜬다).
- **스택은 그래프 창마다 하나다**(사용자 확인). 창에 포커스가 있으면 실행 취소·다시 실행·지우기·복사·붙여넣기·복제·저장은 그 창의 행동이 받는다.
- 끌어 옮기기는 끄는 동안 미리 그리고 놓을 때 커맨드 하나로 확정한다(기즈모와 같은 모양). 값 끌기는 같은 칸이면 합친다.
- 저장은 따로다. 창 제목에 저장 안 됨 표시를 단다.

### 2.4 에셋과 샘플 도메인

- 에셋 `NodeGraph`(`.jgraph`). 본문이 그래프 YAML 이고 첫 키 `Domain` 이 도메인 이름이다. 에셋 브라우저 우클릭 `새 노드 그래프` 로 만들고, 두 번 눌러 연다.
- 샘플 도메인 `Math` - 다듬기용이다. 핀 타입 `Float`·`Vector2`·`Vector3`·`Color`, 노드 `Float`·`Vector2`·`Color`·`Add`·`Subtract`·`Multiply`·`Divide`·`Sin`·`Lerp`·`Output`.
  `Float` 는 무엇으로도 넓혀진다. 계산기 `EvaluateMath` 가 위상 순서로 값을 내 "그래프를 결과물로 바꾸는 컴파일러" 자리를 시험한다.
