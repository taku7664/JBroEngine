# 3D 남은 일

> 공용 남은 일과 Decisions 는 `todo.md`, 2D 는 `todo-2d.md` 다(D-116). 여기는 3D 프레임워크·3D 렌더링·3D 편집의 것만
> 적는다. **2D 를 멈추고 3D 를 먼저 한다(D-335, D-116 의 순서를 바꿨다).** 순서는 아래 "우선순위" 절이고, 그 아래 절들은
> 영역별 세부다. 실측과 배경은 `framework3d-plan.md` §3.
> 구현을 마친 항목은 지우지 않고 취소선으로 긋고 언제(날짜·커밋)와 어디서(파일·함수) 고쳤는지 붙인다(D-204).

## 우선순위 (D-335, 2026-11-16)

사용자가 3D 프로젝트를 만들어 → 놓고 → 모양을 바꾸고 → 꾸미고 → 움직이고 → 부딪히고 → 내보내는 흐름에서 처음 막히는 곳부터다.
매긴 때의 실측: 컴포넌트는 Transform·Camera·MeshRenderer·Text3D·AudioListener3D 와 골격뿐인 `Physics3D`, 시스템은 Transform·
Camera·MeshRender·Text·Audio, 캔버스 뷰는 궤도 카메라·3D 집기·바닥 격자·기즈모를 가진다. 메시는 `MeshLibrary::BuiltinCubeId` 하나,
빛은 `BuiltinMesh.hlsl` 안의 고정 방향광 하나, `Framework3D/Scripting/GameScript.h` 는 기반 타입 검사만 한다.
